# Rockit

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Self-hosted music playback with a personal library and social listening.

## Capabilities and Constraints

Repository evidence: Friends supports friend search and requests, blocking,
listening activity, shared music, listening sessions, and a listening leaderboard.
Keep these capabilities and existing managers. The initial visual redesign does not change backend behavior; the separate stacked listening-rewards PR implements XP and emblems.

## Brand Commitments

The user requests a distinctive Friends experience without the current repeated
boxes, informed by Apple Design and Impeccable. Preserve Rockit's surrounding app.

## Open Decisions

The user confirmed the mobile order: friends/current listening, shared music,
then recent circle activity. Personal progress and comparison are secondary.
They also requested listening-time XP milestones and branded comparable emblems.
