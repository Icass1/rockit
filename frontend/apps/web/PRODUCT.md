# Rockit

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Self-hosted music playback with a personal library and social listening.

## Capabilities and Constraints

Repository evidence: Friends supports friend search and requests, blocking,
listening activity, shared music, listening sessions, and a listening leaderboard.
Keep these capabilities and existing managers. No backend changes in this redesign.

## Brand Commitments

The user requests a distinctive Friends experience without the current repeated
boxes, informed by Apple Design and Impeccable. Preserve Rockit's surrounding app.

## Open Decisions

The proposed priority is people and music before competition. This is a design
assumption awaiting user feedback, not a confirmed product-wide policy.
