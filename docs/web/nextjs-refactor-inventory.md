Every listed file was parsed/scanned. Detailed design findings are based on source tracing in the plan; a scan flag is not a defect finding or a record of browser execution. Shared/backend contracts are traced separately in the plan.

A **client** flag means a direct `use client` directive; files without it may still enter the client graph through imports. HTTP names are direct calls detected by syntax, so passed fetch functions and manager calls may not appear. **Palette** flags include raw Tailwind palette classes, SVG/asset values and color literals; migrate interface colors and review legitimate asset exceptions. Native control counts describe elements to consolidate, not automatic accessibility failures. Line counts are source lines at this snapshot.
